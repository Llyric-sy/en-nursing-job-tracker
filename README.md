# EN Nursing Job Tracker

GitHub Pages-ready tracker for the EN job search.

## Files
- `index.html` – interactive tracker UI
- `jobs.json` – master job data updated by ChatGPT
- Status buttons are stored locally in the browser, so published job refreshes do not overwrite your personal Applied / Disregarded / Considering / Closed choices.
- The Excel button generates a fresh `.xlsx` from the current published master list in the browser.

## Publish with GitHub Pages
Create this repository as `en-nursing-job-tracker`, add these files to the `main` branch, then in GitHub open:
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.

The expected Pages address will normally be:
`https://llyric-sy.github.io/en-nursing-job-tracker/`
